# Renoza MVP Spec

## MVP Workflow

1. User creates a room renovation project.
2. User uploads room photos.
3. User adds location, room type, budget, ownership, approximate size, and goals.
4. Renoza generates a practical renovation plan.
5. Renoza produces a WhatsApp-ready contractor brief.
6. User can paste a contractor quote for review.

## Required Pages

- `/` Dashboard or start screen
- `/projects/new` New renovation project
- `/projects/[id]` Project details and generated plan
- `/quote-review` Quote review tool

## Renovation Plan Output

- Room summary
- Recommended approach
- Budget realism note
- Suggested work items
- Materials list
- Labour categories needed
- Estimated cost range
- Risks and hidden costs
- Questions for contractor
- WhatsApp contractor brief

## Quote Review Output

- Quote summary
- Missing details
- Red flags
- Fairness estimate
- Questions to ask before paying
- Rewritten contractor scope
